Create a practice test —

Pick whole modules or individual inquiry questions, then set how many marks of each question type to include. Questions are chosen at random from the selected topics, and the official marking guidelines are appended as an answer sheet.

Marking needs your own Anthropic API key. It is kept in this browser only, never in the repository or the published page.

How do I get a key? — step by step
  1. Go to console.anthropic.com/settings/keys and sign in (or create an account — it is separate from a Claude subscription).
  2. You need credit before a key will work: open Billing and add some. A few dollars marks hundreds of questions.
  3. While you are there, open Limits and set a monthly spend cap. This is the safety net if a key ever leaks.
  4. Back on the Keys page, press Create Key, name it hsc-sorter, and press Create.
  5. Copy it now — it starts sk-ant- and is shown only once.
  6. Paste it in the box above and press Save. It is remembered in this browser, so you only do this once per device.

If marking fails: "invalid x-api-key" means the key was mis-copied or deleted; "credit balance is too low" means step 2 is outstanding.

              Flashcards

              Your cards live in this browser only. Clearing site data deletes them — export a copy to keep them safe.

              Sync across devices — optional

              Keeps the same cards on every device, through a private GitHub repository you own. No server, and nothing is shared with anyone else. Set it up once per device.

              Step by step — about two minutes
              1. Make the store. Go to github.com/new. Name it hsc-flashcards, choose Private, tick Add a README file, then Create repository. Tick the README — a repository with no files in it cannot be written to yet. Do this once, not once per device.
              2. Make a token. Go to github.com/settings/personal-access-tokens/new (Settings → Developer settings → Personal access tokens → Fine-grained tokens).
              3. Name it hsc-sorter-sync and pick an expiry. When it expires syncing stops and you make a new one.
              4. Under Repository access choose Only select repositories and pick hsc-flashcards. A token can only ever reach repositories chosen here. One made before the repository existed will not see it.
              5. Under Permissions → Repository permissions, find Contents and set it to Read and write. Leave everything else alone. This is the step most easily missed, and without it syncing cannot save anything.
              6. Press Generate token and copy it. It starts github_pat_ and is shown only once.
              7. Fill the two boxes below — repository your-username/hsc-flashcards, then the token — and press Connect.

              On another device: repeat steps 2–7 only. Same repository, its own token. Its first sync pulls everything down.

              The token is kept in this browser only, exactly like the Anthropic key, and is never written into the repository.
